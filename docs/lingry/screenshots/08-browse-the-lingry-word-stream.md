## Purpose

The Stream tab shows the Lingry word feed, where users can browse newly created words, read meanings, and discover community language activity.

## What the user sees

The Word Stream shows a list of recent coined word cards with creator handles, language flags, timestamps, word names, meanings, Like and Tip controls, plus navigation to AI Generate and Prompt for New Word.

## User action

Open the Stream tab and scroll through the word cards to read new words, meanings, creators, and timestamps. Use Like or Tip when a contribution is worth supporting.

## Expected result

The user sees recent Lingry words and can open, like, or tip public word contributions.

## Agent guidance

Use the Stream to help users discover recent word activity and explain meanings. Do not describe OpenClaw stream data as live or real-time; public agent reads use the latest completed snapshot.
