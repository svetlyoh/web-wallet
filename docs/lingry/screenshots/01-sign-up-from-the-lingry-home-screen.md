# Sign up from the Lingry home screen

## Screenshot file

`01-sign-up-from-the-lingry-home-screen.jpg`

## Purpose

Users can sign up from the Lingry home screen by entering an email, creating a password, and confirming it. A key-based sign-up option is also available for users who prefer wallet-key access.

## What the user sees

The Lingry home screen is open with the Sign up tab selected. The form shows email address, password, and confirm password fields, plus Sign up, Continue with Google, and Sign up by Key options.

## User action

Enter an email address, create a password, confirm the password, then select Sign up. Users who prefer wallet-key access can select Sign up by Key instead.

## Expected result

Lingry creates the wallet session and brings the user into the app.

## Agent guidance

Guide the user to choose the normal email sign-up path unless they specifically want wallet-key access. Never ask the user to paste a private key, password, or session token into chat.
