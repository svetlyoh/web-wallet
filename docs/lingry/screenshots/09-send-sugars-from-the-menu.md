# Send Sugars from the menu

## Screenshot file

`09-send-sugars-from-the-menu.jpg`

## Purpose

From Menu > Send, users can transfer Sugars to another wallet address by entering the recipient, amount, and fee, then confirming the transaction.

## What the user sees

The Send screen shows the current Sugar balance, recipient address and amount inputs, a fee input with recommended-fee placeholder text, a Send button, and a Reset button.

## User action

Open Menu, choose Send, enter the recipient wallet address, enter the Sugar amount and fee, then select Send only after reviewing the details.

## Expected result

Lingry prepares the wallet transfer flow so the user can confirm and submit a Sugar transaction to the chosen recipient.

## Agent guidance

Help the user verify the recipient address, amount, and fee before sending. Never invent transaction status or claim a transfer succeeded until Lingry or the wallet confirms it.
