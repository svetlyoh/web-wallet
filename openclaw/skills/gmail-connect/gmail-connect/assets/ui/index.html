Prepare your Google project

One-time setup in your own Google account. No Google Cloud CLI needed.

Create or choose a project

Use a dedicated project so this connection is easy to manage.

Open Google Cloud ↗

Paste the project ID, not its display name. The buttons below will use it.

  1. Enable Gmail API ↗

    Check the selected project and click Enable.

  2. Configure Google Auth Platform ↗

    Complete Branding and Audience. Personal Gmail: choose External and add yourself as a test user. In Data Access, add gmail.readonly; add gmail.send only if you want sending.

    External apps in Testing can lose Gmail refresh tokens after 7 days. For lasting personal use, review Google’s Production and verification requirements. Publishing an OAuth app is separate from publishing this ClawHub skill; Workspace policies may still block it.

  3. Create a Desktop OAuth client ↗

    Clients → Create client → Desktop app. Download its JSON file. Google may ask you to complete consent setup first.

Background checks update a local feed about once a minute while this computer is awake. Your OpenClaw agent can read it using the skill. Automatic Telegram messages require a separately configured OpenClaw heartbeat or automation.

Keep checking after logout or a cold boot

User services normally start with your login. For unattended operation, run this one administrator command in your Ubuntu terminal:

sudo loginctl enable-linger "$USER"

This keeps your user’s services available. It does not prevent sleep or start OpenClaw’s gateway.

Need immediate push notifications?

This version uses direct Gmail polling. Native OpenClaw Pub/Sub with Tailscale Funnel is an advanced alternative covered in references/native-push.md. It is not activated by this wizard.
